# Встановлення в CasaOS

Бот — це **polling-воркер**: у нього немає веб-інтерфейсу й відкритого порту. Після запуску ви спілкуєтесь із ним у Telegram, а не через браузер. Тому в CasaOS плитка застосунку не матиме кнопки «Open Web UI» — це нормально.

Образ **мультиархітектурний** (`amd64` + `arm64`), тож він працює і на звичайному ПК, і на Raspberry Pi / ARM-міні-ПК.

---

## Що потрібно заздалегідь

1. **Токен бота.** У Telegram напишіть [@BotFather](https://t.me/BotFather) → `/newbot` → скопіюйте токен виду `123456:ABC-DEF...`.
2. *(Необов'язково)* **Ключ Gemini API** для AI-пояснень «чому тривога» — [aistudio.google.com/apikey](https://aistudio.google.com/apikey). Без нього бот усе одно відповідає живими даними NEPTUN.

---

## Спосіб 1 — Імпорт готового compose (рекомендовано)

1. У CasaOS відкрийте **App Store → Custom Install** (значок `+` вгорі праворуч).
2. Натисніть **Import** і вставте вміст [`casaos/docker-compose.yml`](../casaos/docker-compose.yml).
3. У полі **BOT_TOKEN** впишіть токен від BotFather. За бажанням заповніть **GEMINI_API_KEY**.
4. Натисніть **Install**.

Через кілька хвилин (першого разу образ завантажується, а межі карти підтягуються з мережі) напишіть боту `/status` — він покаже стан потоку NEPTUN, API та черги рендеру.

## Спосіб 2 — Вручну через образ

1. **App Store → Custom Install → Docker CLI** або форма з полями.
2. Образ: `uasneppy/ukrainealertsbot:latest`
3. Змінні середовища:
   | Змінна | Значення |
   | --- | --- |
   | `BOT_TOKEN` | токен від @BotFather (**обов'язково**) |
   | `GEMINI_API_KEY` | ключ Gemini (необов'язково) |
   | `TZ` | `Europe/Kyiv` |
4. **Volumes** (саме іменовані томи, не bind-mount — див. нижче чому):
   | Том | Шлях у контейнері |
   | --- | --- |
   | `subscriptions` | `/app/data` |
   | `geo-cache` | `/app/neptun/geo` |
5. Restart policy: **unless-stopped**. Порт **не** відкривайте.

---

## Важливо про томи (щоб не втратити підписки)

- `/app/data` містить **підписки користувачів і стан тривог**. Це не кеш — якщо видалити том, усі підписки тихо зникнуть, і люди про це не дізнаються, доки не пропустять тривогу. Не чіпайте його.
- `/app/neptun/geo` — це кеш меж карти, його видаляти безпечно (завантажиться знову).

**Чому іменовані томи, а не bind-mount у `/DATA/AppData`:** контейнер працює під non-root користувачем `node` (uid 1000). Свіжий іменований том успадковує правильного власника з образу, тож запис одразу працює. Bind-mount у `/DATA/AppData` належав би `root`, і бот не зміг би записати підписки. Якщо вам таки потрібен bind-mount (наприклад, для бекапів через файловий менеджер CasaOS), виконайте на хості:

```bash
sudo mkdir -p /DATA/AppData/ukrainealertsbot/data
sudo chown -R 1000:1000 /DATA/AppData/ukrainealertsbot
```

## Перевірка й обслуговування

- **Живий чи ні:** CasaOS показує healthcheck-статус плитки. Бот раз на 30 с оновлює файл `/app/data/heartbeat`; якщо він застаріває понад 2 хв, контейнер позначається `unhealthy` (це ловить «завис, але процес живий» — а не лише падіння).
- **Стан зсередини:** напишіть боту `/status`.
- **Логи:** кнопка логів на плитці CasaOS. Логи обмежені (10 МБ × 3 файли), диск не переповниться.
- **Оновлення:** CasaOS → плитка → **Update** підтягне новий `:latest`. Томи переживають оновлення.

## Часті проблеми

| Симптом | Причина / рішення |
| --- | --- |
| Контейнер одразу перезапускається | Не заданий або хибний `BOT_TOKEN`. Перевірте логи — має бути `BOT_TOKEN is required`. |
| Карти не будуються, текст відповідей є | Замало пам'яті для Chromium. Дайте контейнеру ≥ 1.5 ГБ або знизьте `--max-old-space-size` (див. коментар у `neptun/browser.js`). |
| «AI-аналіз недоступний» | Немає або хибний `GEMINI_API_KEY`. Бот навмисно деградує до живих даних NEPTUN; `/status` покаже точну причину. |
| Плитка без іконки | До репозиторію ще не додано `casaos/icon.png`. На роботу не впливає. |
