# Air Raid Alerts Telegram Bot

[![CI](https://github.com/uasneppy/ukrainealertsbot/actions/workflows/ci.yml/badge.svg)](https://github.com/uasneppy/ukrainealertsbot/actions/workflows/ci.yml)
[![Docker Image](https://img.shields.io/docker/v/uasneppy/ukrainealertsbot?sort=semver&label=docker%20hub)](https://hub.docker.com/r/uasneppy/ukrainealertsbot)

Telegram-бот, який показує актуальну карту повітряних загроз в Україні: відповідає мапою на слово **«тривога»**, будує наближену мапу окремого регіону, пояснює причину тривоги за допомогою AI та надсилає сповіщення про тривогу й відбій за підпискою.

Дані — з живого потоку **NEPTUN** (`neptun.in.ua`): WebSocket для оновлень у реальному часі та REST як резерв. Мапа не є скріншотом чужого сайту — вона рендериться власноруч у headless Chromium (Puppeteer + Leaflet), тому вигляд, підписи й масштаб контролюються повністю.

## ✨ Можливості

| Запит | Що робить |
| --- | --- |
| **«тривога»** | Мапа загроз по всій Україні: області та райони з тривогою, маркери загроз, легенда |
| **«&lt;місто/область&gt;»** (напр. «Київ», «Київщина», «Харківська область») | Найкоротша форма — сама лише назва регіону. Наближена мапа регіону з підписами загроз. Також працює «карта києва», «тривога київ» |
| **«тривога в &lt;місто/область&gt;»** | Те саме, повна форма |
| **«чому тривога»** | AI-підсумок останніх повідомлень каналу Повітряних сил (@kpszsu) |
| **«чому &lt;регіон&gt;»** / **«чому тривога в &lt;регіон&gt;»** | AI-пояснення саме для регіону: живі дані NEPTUN + повідомлення ПС |
| **`/map <регіон>`** | Мапа регіону на вимогу (напр. `/map харківщина`) |
| **`/subscribe <регіон>`** | Підписка на сповіщення про тривогу та відбій у регіоні |
| **`/unsubscribe [регіон\|all]`** | Скасування підписки |
| **`/subscriptions`** | Список активних підписок чату |
| **`/settings`** | Що саме надсилати цьому чату: тривога/відбій, цілі поблизу, балістика, МіГ-31К, стратегічна авіація, «Калібри», пуски БпЛА — кнопками. У групах доступно лише адміністраторам |
| **`/status`** | Стан бота: потік NEPTUN, API, AI-аналіз, черга рендеру, підписки |

Під кожною мапою — кнопки **🔄 Оновити** та **🔔 Підписатися**: під час тривоги натиснути швидше, ніж набирати текст. Оновлення замінює саме зображення, а не додає нове повідомлення.

За замовчуванням мапа самодостатня (лише межі, рендер офлайн, без чужих тайлів). Якщо задати `STADIA_API_KEY`, на **мапі міста** під маркерами зʼявляються **вулиці** — видно, над якою саме вулицею летить загроза. Тайли лише для міського вигляду; область і країна лишаються межовими.

Регіон розпізнається в будь-якому відмінку та в розмовних формах: «Київ», «в Києві», «київській області», «харківщина», «на Буковині», «в Криму». Щоб не спамити в групах, коротка форма спрацьовує лише коли **все повідомлення** і є назвою регіону — «їду в Київ» чи «Харків тримайся» бота не турбують.

### Сповіщення за підпискою

- **Тривога** надсилається одразу, щойно її видно — затримка тут коштує людям часу на укриття.
- **Відбій** надсилається лише якщо він протримався 30 секунд: передчасне «відбій» небезпечніше за його відсутність (налаштовно `CONFIRM_OFF_MS`).
- **Живі сповіщення по швидких цілях** — ракети, балістика, КАБи: окреме повідомлення, коли така ціль **наближається** до регіону і коли **входить** у нього. Подієво (поява / вхід), а не щотік — «ціль зсунулась на кілометр» навмисно не шлеться. Реакція майже миттєва: watcher будиться одразу, щойно потік NEPTUN приносить зміну (а не раз на N секунд), тож нова ціль реєструється за ~2–3 с, а не за десятки. Дрони/FPV/розвідники сюди не входять (їх покриває звичайна тривога й мапа), щоб дронова ніч не перетворилась на потік повідомлень. Набір типів і дистанцію можна змінити (`LIVE_ALERT_TYPES`, `LIVE_ALERT_KM`).
- **Загроза ≠ ціль.** NEPTUN позначає *ризик* («Балістична загроза» над містом, МіГ-31К у повітрі) тими самими типами, що й реальні цілі. Бот розрізняє їх: попередження надсилається як **⚠️ Загроза балістики — Київ** із поясненням, що це ризик, а не зафіксований пуск, — і лише **один раз** на регіон (`ADVISORY_QUIET_MS`, типово 30 хв), скільки б разів джерела не повторювали його вночі. «Балістика наближається, ~40 км» для ракети, якої ніхто не запускав, більше не буває.
- **Загальнодержавні події** — зліт стратегічної авіації (Ту-95/Ту-160), пуски крилатих ракет, зліт МіГ-31К і пуски «Кинджалів», носії «Калібрів» у морі та їх пуски, старт ударних БпЛА з кількістю. Читаються зі стрічки моніторингових каналів, яку агрегує NEPTUN (Повітряні сили @kpszsu та розвідувальні канали; список — `EVENT_CHANNELS`), а зліт МіГ-31К — ще й з мапи загроз. Кожна подія надсилається **один раз** за вікно (`EVENT_COOLDOWN_MS`, типово 30 хв; для пусків дронів — 10 хв, бо там новина — кількість) усім чатам, що мають хоч одну підписку, з цитатою джерела та часом. Після перезапуску стрічка лише «засівається» — останні 10 хвилин повідомлень не розсилаються повторно.
- **Налаштування по чату** — `/settings` показує кнопки-перемикачі для кожної категорії; вимкнене не надсилається. У групах змінювати їх можуть лише адміністратори (перевіряється через Telegram; анонімні адміни теж проходять). Один і той самий ризик, що прийшов двома шляхами (позначка NEPTUN над містом і повідомлення ПС), у чат потрапляє раз.
- Якщо потік даних застарів (обірваний сокет), сповіщення **не надсилаються взагалі** — мовчання краще за неправдиве «відбій».
- Після перезапуску бот не розсилає повторно те, що вже триває — але **звіряє** стан і повідомляє про зміни, що сталися, поки він був недоступний.

## 🏠 Встановлення в CasaOS

Готовий образ (`amd64`) — на [Docker Hub](https://hub.docker.com/r/uasneppy/ukrainealertsbot). Покрокова інструкція: **[docs/INSTALL-CasaOS.md](docs/INSTALL-CasaOS.md)**. Маніфест для імпорту — [`casaos/docker-compose.yml`](casaos/docker-compose.yml).

## 🐳 Запуск з готового образу

```bash
docker run -d --name ukrainealertsbot --restart unless-stopped \
  -e BOT_TOKEN=<токен від @BotFather> \
  -e GEMINI_API_KEY=<необов'язково> \
  -e TZ=Europe/Kyiv \
  -v ukrainealerts-data:/app/data \
  -v ukrainealerts-geo:/app/neptun/geo \
  uasneppy/ukrainealertsbot:latest
```

`-v …:/app/data` обов'язковий — це підписки, налаштування сповіщень і стан тривог, а не кеш.

## 🚀 Запуск через Docker Compose (збірка з коду)

```bash
cp .env.example .env      # і вписати BOT_TOKEN
docker compose up -d --build
docker compose logs -f
```

Compose уже налаштований для довготривалої роботи на VPS: перезапуск після падінь і ребуту, `tini` як PID 1 (щоб Chromium не лишав зомбі-процесів), ліміти CPU/памʼяті, обмеження розміру логів і коректне завершення по SIGTERM.

Два томи, обидва важливі:

- `geo-cache` → `/app/neptun/geo` — кеш меж областей і районів, щоб не завантажувати їх щоразу.
- `subscriptions` → `/app/data` — підписки користувачів. **Без цього тому кожен `docker compose up` тихо стирає всі підписки.**

### Локальний запуск

```bash
npm install
node bot.js
```

Потрібен Chromium: або системний (`chromium` / Google Chrome), або через змінну `CHROME_EXECUTABLE_PATH`.

## ⚙️ Змінні середовища

| Змінна | Обовʼязкова | Призначення |
| --- | --- | --- |
| `BOT_TOKEN` | так | Токен бота від @BotFather |
| `GEMINI_API_KEY` | ні | Вмикає AI-аналіз («чому тривога»). Без нього бот віддає живі дані NEPTUN без пояснення |
| `TZ` | ні | Часовий пояс для логів (напр. `Europe/Kyiv`) |
| `CHROME_EXECUTABLE_PATH` / `PUPPETEER_EXECUTABLE_PATH` | ні | Шлях до Chromium, якщо автовизначення не спрацювало |
| `MAX_CONCURRENT_RENDERS` | ні | Скільки мап рендериться одночасно (типово `2`) |
| `STADIA_API_KEY` | ні | Безкоштовний ключ [Stadia Maps](https://stadiamaps.com) — додає вулиці під маркерами на мапі міста |
| `CITY_TILES_URL` | ні | Власне джерело тайлів `{z}/{x}/{y}` (перекриває `STADIA_API_KEY`) |
| `CITY_TILES_ATTRIBUTION` | ні | Текст атрибуції для власних тайлів |
| `THREAT_ICONS_DIR` | ні | Тека з іконками загроз (типово `./icons`) |
| `NEPTUN_GEO_DIR` | ні | Тека кешу GeoJSON |
| `SUBSCRIPTIONS_FILE` | ні | Файл зі сховищем підписок (типово `./data/subscriptions.json`) |
| `ALERT_STATE_FILE` | ні | Останній стан тривог для звірки після перезапуску |
| `LIVE_ALERT_TYPES` | ні | Типи для живих сповіщень по цілях (типово `missile,ballistic,kab`; `none` — вимкнути). МіГ-31К — загальнодержавна подія, не ціль |
| `LIVE_ALERT_KM` | ні | На якій відстані «наближення» цілі вважається значущим (типово `120`) |
| `ADVISORY_QUIET_MS` | ні | Скільки регіональне попередження (загроза балістики) мовчить після одного сповіщення (типово `1800000`, 30 хв) |
| `EVENT_CHANNELS` | ні | Канали зі стрічки NEPTUN, що можуть запустити загальнодержавну подію (типово `@kpszsu,@rozvidkaneba,@ukrainian_intelligence`; `all` — усі; `none` — вимкнути) |
| `EVENT_POLL_MS` | ні | Період опитування стрічки подій (типово `20000`) |
| `EVENT_COOLDOWN_MS` | ні | Вікно «один раз» для кожного виду події (типово `1800000`, 30 хв) |
| `EVENT_UAV_COOLDOWN_MS` | ні | Те саме для пусків БпЛА (типово `600000`, 10 хв) |
| `CHAT_SETTINGS_FILE` | ні | Файл налаштувань сповіщень по чатах (типово `./data/chatSettings.json`) |
| `WATCHER_INTERVAL_MS` | ні | Період фонової перевірки підписок (типово `8000`); швидкий шлях — миттєве пробудження від потоку |
| `CONFIRM_OFF_MS` | ні | Скільки відбій має протриматись до відправки (типово `30000`; менше — швидший відбій, але вищий ризик передчасного) |
| `HEARTBEAT_FILE` | ні | Файл живучості для healthcheck контейнера |

## 🎨 Іконки загроз

Файл `icons/<тип>.<png\|svg\|webp\|jpg\|gif>` перевизначає маркер для цього типу: `uav`, `fpv`, `missile`, `ballistic`, `kab`, `recon`, `mig31k`, `unknown`. Тека читається на кожному рендері — іконки можна міняти без перезапуску. Без своїх файлів використовуються вбудовані SVG-бейджі (не emoji: у headless Chromium emoji залежать від шрифтів і перетворюються на «тофу» □).
