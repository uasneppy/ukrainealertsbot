# Air Raid Alerts Telegram Bot

Telegram-бот, який автоматично генерує актуальну карту повітряних тривог в Україні та надсилає її у відповідь на повідомлення **“тривога”** в груповому чаті.  
Бот працює поверх офіційного API **alerts.in.ua**, використовує headless-браузер Puppeteer та оптимізований механізм очікування рендерингу карти.

---

## ✨ Основні можливості

- Реагує на слово **“тривога”** в групових чатах  
- Генерує скріншот карти тривог із `alerts.in.ua`  
- Підсвічує області та райони з активними тривогами  
- Працює через Puppeteer + @sparticuz/chromium  
- Має резервний механізм очікування рендеру карти  
- Підтримує команду **“чому тривога”** — показує останні повідомлення з Telegram-каналу
- **“тривога в &lt;місто/область&gt;”** (напр. «тривога в Києві», «тривога в київській області») — детальна наближена мапа регіону з підписом кожної загрози окремо
- **“чому тривога в &lt;місто/область&gt;”** — AI-пояснення саме для цього регіону: живі дані NEPTUN (загрози в регіоні та поруч, статус тривоги) + останні повідомлення Повітряних сил
- **`/map <регіон>`** — детальна мапа регіону на вимогу (напр. `/map харківщина`)

---

## 🛠 Технології

- Node.js (ESM)  
- Puppeteer  
- @sparticuz/chromium  
- Telegram Bot API  
- dotenv  
- Canvas / Leaflet selector handling  

---

## 🚀 Як працює

1. Користувач пише **“тривога”**  
2. Бот піднімає headless Chromium  
3. Завантажує `https://alerts.in.ua/`  
4. Очікує рендеру canvas-елементів  
5. Робить PNG-скрін карти  
6. Відповідає знімком у чат

---

## 📦 Встановлення та запуск

### Встановлення

```npm install```

Створи файл .env:

```BOT_TOKEN=your_telegram_bot_token```

Запуск
```node bot.js```

Запуск через PM2
```pm2 start bot.js --name alerts-bot```
```pm2 save```
