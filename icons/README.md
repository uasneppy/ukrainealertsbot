# Іконки цілей на мапі

Поклади сюди свої картинки — і бот використає їх як маркери цілей на мапі.

## Як це працює

Ім'я файлу = тип цілі з NEPTUN, розширення — будь-яке з: `png`, `jpg`, `jpeg`, `webp`, `gif`, `svg`.

| Файл | Ціль |
|---|---|
| `uav.png` | БпЛА (Shahed тощо) |
| `fpv.png` | FPV-дрон |
| `missile.png` | Крилата ракета |
| `ballistic.png` | Балістика |
| `kab.png` | КАБ |
| `recon.png` | Розвідувальний БпЛА |
| `mig31k.png` | МіГ-31К |
| `unknown.png` | Невідома ціль |

Якщо NEPTUN колись почне віддавати інший тип (наприклад `cruise`) — просто додай файл із такою самою назвою: `cruise.png`.

## Поради

- Рекомендований розмір: **64–128 px**, квадратна картинка з прозорим фоном (PNG/WebP).
- Файли понад 1 МБ ігноруються.
- Папка перечитується під час кожного рендера мапи — **перезапускати бота не треба**, нова іконка з'явиться протягом ~30 секунд.
- Якщо файлу для типу немає — бот малює стандартний вбудований значок (кольоровий бейдж із символом цілі).
- У Docker/на VPS папка прокинута як volume (`./icons:/app/icons:ro` у `docker-compose.yml`), тож іконки можна міняти прямо на сервері без перебудови образу.
